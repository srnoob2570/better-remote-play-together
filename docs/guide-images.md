# Imágenes de la guía

La guía usa cinco capturas reales de Steam proporcionadas por el usuario,
tomadas el 20/10/2026 (Steam build 1791918634) en la interfaz española:

| Recurso | Contenido | Estado |
|---|---|---|
| `frontend/public/guide/library-properties.png` | Biblioteca → clic derecho en SpaceWar → Propiedades | Captura real |
| `frontend/public/guide/launch-options.png` | Propiedades → General → Opciones de lanzamiento, campo vacío | Captura real |
| `frontend/public/guide/command.png` | El mismo campo con el comando pegado | Captura real |
| `frontend/public/guide/popup.png` | Aviso «Iniciar el juego con argumentos personalizados» | Captura real |
| `frontend/public/guide/invite.png` | Overlay → menú de SpaceWar → Invitar a Remote Play | Captura real |

Todas están recortadas a 1200×480 (proporción 2.5:1) y se muestran a todo el
ancho de la guía, sin recortes: la altura se deriva del ancho. La captura del
overlay está recortada al menú contextual para no incluir perfiles de terceros.
No se ocultaron la cuenta, la ruta ni el token en las capturas donde aparecen;
son datos del propio usuario y no se consideran sensibles para esta guía local.

## Regla

No se inventan capturas ni se presentan diagramas como capturas reales. Las
cinco imágenes son capturas de Steam. Si se sustituyen, mantener el recorte
2.5:1 y ocultar únicamente datos de terceros.

## Procedimiento de sustitución

1. Abrir Steam y la ventana o el menú que se quiera capturar.
2. Capturar con la herramienta del escritorio.
3. Recortar a 1200×480, centrando el diálogo o la sección relevante.
4. No incluir perfiles de terceros en la captura del overlay.
5. Guardar como PNG en la ruta correspondiente.
6. Verificar que la imagen se vea en ES/EN y en 1024/1280 px.
7. Actualizar esta tabla con la fecha y la versión de Steam.
