# Better RPT frontend

React + TypeScript + Vite served by Wails v3. The library dashboard is
implemented in this ticket; the session panel and dialogs arrive in ticket 11.
The UI uses the shared i18n catalogs, `design/tokens.css`, Tailwind and the
shadcn primitives in `src/components/ui`.

```bash
npm ci
npm run dev      # Vite on 9245 when launched by `wails3 dev`
npm run build    # tsc + Vite -> ../cmd/better-rpt/dist
npm test         # Vitest with mocked bridge bindings
```

Bindings are generated by Wails and committed:

```bash
wails3 generate bindings -ts -i -clean=true -f '-tags gtk3' ./...
```

`src/bridge/wails.ts` adapts the generated bindings to the manual `Bridge`
contract. Do not edit `bindings/` by hand.

Artwork is served same-origin at `/api/art/{appId}/{cover|icon}` by the Go asset
middleware; use `artUrl` from `src/art.ts`. A 404 means there is no artwork and
the UI should keep the typographic fallback.
